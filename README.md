# Meteor Night for TidaLuna

Meteor Night is a TidaLuna plugin that brings a cosmic, glassmorphism interface to TIDAL.

## Features

- Glassmorphism and a nocturnal background
- Transparent panels while preserving album artwork
- Animated meteor shower over the entire interface
- Optimized `transform` and `opacity` animations
- `prefers-reduced-motion` support

## Development

```sh
pnpm install
pnpm run watch
```

In TidaLuna, open **Luna Settings → Plugin Store → DEV Store → MeteorNight**.

## Build

```sh
pnpm run build
```
